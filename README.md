## 📌 About the Project

This is my **first web development project**, created as a personal portfolio to showcase my journey as a Computer Science & Engineering student.

The website presents my:

* 👩‍💻 Introduction
* 🎓 Education
* 🛠️ Technical Skills
* 🚀 Projects
* 📜 Certifications
* 📬 Contact Information

The project focuses on creating a clean, interactive, and responsive portfolio experience using core frontend technologies.

---

## ✨ Features

### 🏠 Home Section

* Personal introduction
* Developer-focused presentation
* Call-to-action elements

### 👩‍💻 About Me

* Educational background
* Personal developer journey
* Career interests

### 🛠️ Skills

Showcases technical skills and areas of interest using an organized visual layout.

### 🚀 Projects

Displays selected projects with descriptions and links for exploring individual repositories.

### 📜 Certifications

Highlights completed courses, certifications, and learning achievements.

### 📱 Responsive Design

Designed to work across different screen sizes including:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

### 🎨 Interactive UI

Uses JavaScript to enhance user interaction and provide a smoother browsing experience.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Trishitapalchowdhury221/Demo_Portfolio.git
```

### 2. Open the Project

```bash
cd Demo_Portfolio
```

### 3. Run the Website

Simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** for a better development experience.
